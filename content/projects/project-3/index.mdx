DEWan personalizes video to a specific subject without any fine-tuning. It does this by folding DiffEdit-style semantic masking into Alibaba's Wan 2.1 model, so generation preserves a subject's identity using only reference images at inference time.

## The Problem

Personalizing video generation usually means fine-tuning per subject, the way DreamBooth and LoRA do. That is expensive, needs several reference images per subject, and has to be redone for every new identity. It does not fit real-time use or limited compute.

## The Approach

I kept the whole thing at inference time. DiffEdit-style masking detects the regions that belong to the target subject and turns them into attention masks. Those masks guide Wan 2.1's cross-attention during denoising: preserved regions stay anchored to the reference features, while the background follows the text prompt. Wan 2.1's temporal layers hold identity and motion steady across frames.

The result is zero per-subject training. You point it at reference images and it personalizes immediately.

## Results

I evaluated DEWan on the OpenS2V-Nexus benchmark. It ranked 2nd in single-domain and 4th in human-domain identity preservation, while running roughly 10x faster than fine-tuning-based methods because there is no training step.

There are real trade-offs. Cross-domain transfer (for example human to animal) is harder, keeping masks consistent across frames took careful temporal smoothing, and fine-tuned methods still edge it out in some cases. The honest takeaway: DiffEdit's masking, built for image editing, transfers to video better than expected, and well-guided cross-attention is a strong lever for identity preservation.
