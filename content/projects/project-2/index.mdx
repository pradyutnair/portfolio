DCP Guardian is an internal tool I built at TomTom to automate the validation of Data Collection Plans. It turns a slow, manual document review into a structured agent workflow.

## The Problem

Validating a Data Collection Plan means checking it across several disconnected sources at once: GitHub pull requests, Confluence pages, event definitions, and metrics coverage. Reviewers did this by hand. It was slow, easy to get wrong, and rarely consistent between people.

## The Solution

I built a multi-step pipeline on the Agno framework. Specialised agents each own one part of the review, run in parallel where they can, and branch on results. If template validation fails, the plan gets immediate feedback. If it passes, the pipeline runs the full pass: PR review, event validation, and metrics assessment.

Azure OpenAI handles the analysis. ChromaDB stores the event and metrics knowledge bases as vectors for retrieval, and SQLite keeps session state and memory across steps.

## What I Learned

State management was the hard part here. Keeping consistent output formatting and session state across many agents took real care, and the Agno executor pattern forced me to be deliberate about how data flows between steps. The result is a review that is repeatable and comprehensive, with far less manual effort. Next steps are wider knowledge bases, more validation rules, and tighter integration with the rest of the toolchain.
